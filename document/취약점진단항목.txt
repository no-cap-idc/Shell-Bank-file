핀테크서비스 취약점 
1) 중요정보보호
- 메모리 내 중요정보 평문 노출 확인
- 웹 영역 내 중요정보 평문 노출 확인
- 파일 내 중요정보 평문 저장 확인
- 화면 내 중요정보 평문 노출 확인
- 중요정보 송수신시 보호대책 적용 확인
- 안전한 HTTPS 적용 확인
2) 거래정보 위/변조
- 계좌정보 무결성 검증 확인
- 금액정보 무결성 검증 확인
- 금액 한도 검증 확인
- 거래정보 재사용 확인
3) 서버 보안
- 리다이렉트 기능을 이용한 피싱 가능성 확인
- 불필요한 메소드 허용 확인
- 외부 사이트에 의한 운영정보 노출 확인
- SQL 인젝션 확인
- 디렉토리 목록화 확인
- 서버 운영정보 노출 확인
- 크로스사이트 스크립팅 확인
- 크로스사이트 리퀘스트 변조 확인
- 파일 업로드 취약점 확인
- 파일 다운로드 취약점 확인
- 관리자 페이지 노출 확인
- 불필요 파일 노출 확인
- 안전한 인증페이지 제공 확인
4) 오픈뱅킹 보안
- 이용기관 주요 기능 수행 및 인증 적용 확인
- 고정된 state 변수 부여 확인
- state 변수 무결성 검증 확인
5) 인증
- 이용자 인증정보 재사용 확인
- 세션/토큰정보 재사용 확인
- 불충분한 세션 만료 확인
- 비밀번호 복잡도 검증 수준 확인
- 비밀번호 오류 횟수 제한 확인
- 불충분한 이용자 인증 확인
- 부적절한 비밀번호 초기화 확인
- 부적절한 인증정보 발급 확인
- 불충분한 인가 확인
- 쿠키정보 변조 확인
- 이체성 거래 시 인증 적용 확인
- 계좌 소유주 검증 확인
